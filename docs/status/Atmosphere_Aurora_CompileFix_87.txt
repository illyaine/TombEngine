Atmosphere Aurora compile fix 87
===============================

Purpose
-------
Fixes the compile errors reported after applying the real-motion Aurora patch.

Fixed errors
------------
- C2440 in Atmosphere.cpp: ScriptColor getters returned RGBAColor8Byte.
  They now return ScriptColor{ ... } directly.
- HLSL0045 in AtmosphereAurora.hlsl: Noise collided with a helper included through CBCamera.hlsli / Math.hlsli.
  Aurora-local helpers are now named AuroraHash and AuroraNoise.

Included files
--------------
- TombEngine/Scripting/Internal/TEN/Flow/Atmosphere/Atmosphere.cpp
- TombEngine/Shaders/AtmosphereAurora.hlsl

Notes
-----
- RendererDraw.cpp is not included in this compile fix. Keep the previously applied real-motion RendererDraw.cpp if it is already in your local tree.
- FORCE_AURORA_DEBUG_VISIBILITY remains a temporary debug setting in FlowLevel.cpp from the previous package.
- Build not run by assistant. Local build/test required.
