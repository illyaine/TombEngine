Atmosphere Aurora / Dome status
================================

Branch: atmosphere_system

Current branch state
--------------------
- The temporary Aurora shader prototype has been removed from the branch.
- `Sky.hlsl` is back to the normal TEN sky shader path and must not be used for Aurora routing.
- `RendererDraw.cpp` is back to the master draw path; the temporary extra sky-grid Aurora draw block has been removed.
- `Aurora.hlsli` is not part of the current branch anymore.
- Aurora profile data still exists in the Flow/Atmosphere data model, but no visible Aurora renderer is active yet.

Why the prototype was removed
-----------------------------
The previous test path tried to route Aurora through the normal sky shader and sky-grid/horizon drawing path. That caused fragile behavior: normal horizon layers could be affected by Aurora marker logic, and Aurora visibility depended too much on glow intensity and the legacy sky/horizon draw order.

That approach is not PR-quality and should not be kept.

Correct Aurora direction
------------------------
Aurora needs a dedicated atmosphere layer, not a `Sky.hlsl` marker hack.

The next implementation should use:

1. A separate Atmosphere/Aurora shader or a dedicated atmosphere sky shader variant.
2. A renderer-side draw path that is clearly named and isolated from legacy sky/horizon drawing.
3. Explicit render order instead of `Color.w` sentinel values.
4. Parameters coming from `Flow.AuroraProfile` / atmosphere render data.
5. No changes to normal horizon layer rendering unless a legacy/atmosphere switch explicitly requires it.

Desired render order
--------------------
1. Atmosphere background / sky dome
2. Aurora layer
3. Celestial bodies: moon, planets, stars, Milky Way, comets
4. Optional legacy horizon for old levels
5. Weather
6. Rooms, objects, overlays

Open renderer work
------------------
- Add a real Atmosphere Sky Dome or shader-only atmosphere background pass.
- Add a proper render switch: legacy horizon, atmosphere dome, or both.
- Add a dedicated Aurora pass after the atmosphere background is stable.
- Move Aurora shader constants to `AuroraProfile` / renderer-facing atmosphere data.
- Keep local/nullmesh atmosphere emitters separate from global sky Aurora.

Current test checklist
----------------------
- Legacy sky and horizon layers should behave as before.
- Aurora should not be visible yet.
- Flow atmosphere data should still load after local compile.
- RendererDraw/Sky shader should no longer contain Aurora prototype leftovers.
- Rain is still the legacy TEN rain fallback and not yet the final Atmosphere rain renderer.
